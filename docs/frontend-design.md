# 前端设计与操作结构

本轮重构覆盖工程列表、新建工程、工程工作台、造价助手、清单编辑、项目资料、共享价格库、材料与定额管理、计价条件、操作记录及全部成果视图。

## 视觉与层级

- 沿用深林绿主色和现有明暗主题。白色内容面与中性工作区背景区分层级，减少阴影与装饰。
- 页面标题、说明、主要动作、正文依次排布。字号使用已有六档变量。
- 首页保留一个新建入口；概况根据清单、缺项和报价状态突出一个下一步。
- 常用条件直接显示，高级筛选、成本明细和管理动作按需展开。
- 数据网格继续使用 `xl-table`，保留粘性表头、行号、冻结金额列、来源和编辑状态。结果页统一外层滚动，避免内容面板重复占用整屏高度。

## 操作路径

新建工程 → 上传资料 → 核对识别结果 → 填计价条件 → 组价与确认写回 → 检查与导出。

五个工作区保持可直接切换：概况、清单、资料、成果、设置。成果列表保留实际标题，以区分同类的不同检查、分析和文件。

桌面保留可拖宽助手；手机将助手放进按需打开的对话面板，关闭、查看结果或核对表格后返回工程。手机清单和结果区各自滚动，表格横向滚动保留在数据容器内。

## 实现边界

`tokens.css` 继续是唯一设计变量源，其余六份样式继续使用 `components` 层；输入、下拉、按钮的尺寸仍通过组件参数指定。布局放在 `shell/` 与样式文件，专业计算、回执、确认门和数据库接口继续使用原有实现。

键盘焦点、跳转到正文、控件标签、对话面板焦点管理、减弱动效和打印样式均纳入页面结构。可用性验证以导入、编辑、确认、撤销、导出及手机操作为重点。国际设计奖水平是设计目标，不能通过编译或测试结果认证。

浏览器验收使用独立数据库和测试工程，覆盖桌面、390px 与 320px 手机视口、明暗主题、映射保存与刷新后批准、工程量计算式编辑与撤销、费用成果跳转、Excel 下载、共享材料导入与行内改价。验收中修正了确认门锁定、旧映射回放、行数预报、小屏工程入口以及图表和卡片描边。
