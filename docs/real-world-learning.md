## 三、确认的导入缺陷（按严重度）

1. **`price` 角色写入 `mainMaterialPrice`**（mapRow.ts:60）：BOQ sheet 中「投标报价单价」「裸单价」若角色判定为 price → 综合单价消失 + 假主材价产生 → 项显示「未定价」且组价链路被污染。reconcilePriceRole 的排除正则含「报价」→ 漏网。
2. **双价/双量对比表被当清单导入**：单价差列静默丢弃，报送价被当合价。
3. **报审/审批类 sheet 当清单导入**：产出无价「清单项」污染计价。
4. **含税单价不标记**：含9%税单价与税前综合单价同列共存时无税态区分 → feeSummary 会重复计税。
5. **无表头错位布局列识别失败**：`名称|量|空|单位|价`（Sheet3 抗震支吊架）positional 回退把价列当 quantity。
6. **层级信息丢弃**：sheet 名【单项工程‖单位工程】、分部行（「消防栓工程」整行标题）、子序号（1.1/1.2）层级未结构化到 sectionPath/unitProject。
7. **「其中」分解列丢弃**：表-08 其中:人工费/材料费/机械费/管理费/利润 是现成的人材机分解，只留了 laborPrice/machinePrice 两列角色。

## 四、对重构的结构性启示

- **数据模型需要层级**：项目 → 单项工程(楼栋/区域) → 单位工程(专业：消防水/通风/电气/给排水) → 分部 → 清单项。BoqItem 需 unitProject 字段；导入时从 sheet 名【A‖B】、扉页、表头「单位工程名称：」提取。
- **文件即工件（artifact）**：每份上传文件属于一个工作流阶段（招标/投标/进度第N期/变更/报审/结算/财评）。ProjectFile 需要 stage + period 维度；fileCompare 应支持「本月 vs 上月进度」「财评 vs 报送」对审——真实对审数据就在文件名和 sheet 里。
- **类型学要扩**：BOQ / QUOTATION / 待报价 / COMPARE(单表双版) / 审批文档 / 汇总事实表 / 材料价表。判定优先级：措施表名 > 对比信号(双价/双量+差值列) > 审批信号(报审/出厂证明/使用部位) > 清单信号 > 材料价信号(材料名称+品牌) > 询价信号 > 有量有价→清单。
- **非导入 sheet 也能产事实**：表-13→规费费率/税率；表-04→单位工程总价真值(交叉验证 feeSummary)；扉页→工程名称/招标人/施工单位台账。
- **价态三维**：税前综合单价 / 含税单价 / 主材暂估价 / 劳务(安装)单价——同一行的价格可以有多个口径，模型要能并挂。

## 五、互联网调研结论（2026-10 检索）

- **GB/T 50500-2024《建设工程工程量清单计价标准》已于 2025-09-01 实施，GB50500-2013 同时废止**（住建部公告）。系统表述层应改口「计价标准」并兼容 2013 时代文件格式（存量文件绝大多数是 2013 口径）。新标准 GB→GB/T 的属性变化体现市场化定价导向——与「材料库价/询价驱动组价」的产品方向一致。
- **宏业（hysware.com，用户实际在用的软件）**：清单计价专家 N10 = 「全过程造价文件编审的智能云计价软件」，自有「造价数据模型」；全过程造价专家 S2 覆盖台账/进度/竣工结算/计量/资料管理；宏业云做造价大数据。→ 印证「项目=全过程文件时间线 + 台账事实库」的重构方向。
- **广联达**：成本（造价）业务主打「DATA+AI，赋能成本每一程」，覆盖估概算→招投标预算→施工过程；项目层级为业界标准的 建设项目→单项工程→单位工程。
- **材料价数据服务口径**（造价通/广材网/造价建材库）：信息价/市场价 × 地区 × 期次 × 品类——与本系统 `MaterialPrice`（normalizePriceType INFO|MARKET|SUPPLY|LABOR + region + period + brand）模型完全一致，现有数据模型无需改口径。
- **全过程阶段→产出文件对照**（与本地文件分布互相印证）：招标控制价 → 投标报价/已标价清单 → 进度款计量申报 → 变更签证 → 材料报审 → 竣工结算 → 财评审核。

## 六、重构设计输入（给设计文档的约束清单）

3. Sheet 类型学扩展：BOQ / QUOTATION / PENDING_QUOTE（待报价） / COMPARE（单表双版） / APPROVAL（报审文档） / FACTS（汇总事实表：表-03/04/13/扉页） / MATERIAL_PRICE（工料机材料价）。

6. ProjectFile 增加 stage/period 维度，支持「本期 vs 上期」对审。
