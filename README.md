# 安装工程造价工作台

基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 官方 `0.2.0-rc.2` Web 面板，安装工程造价功能以 Cordis 插件接入。对话、会话、模型设置和修改确认使用 Harness 原生能力。

## 运行

需要 Node.js 22.19 以上（或 24 以上）。

```sh
npm install
npm run db:push
npm run dev
```

打开启动时打印的 `dsh web` 地址。主入口为 `127.0.0.1:3210`，地址中的令牌用于官方面板的本地访问认证。完整地址保存在 `.harness/web.url`；重启后以新地址为准。

生产运行：

```sh
npm run build
npm start
```

专业数据服务在 `127.0.0.1:3211`，由主入口内嵌打开。进入工程先展开原生 Agent 对话，空对话提供导入资料或测算、检查、汇总三个任务入口。点击「查看清单」或结果卡片才打开右侧工作区；点击工程名称可切换工程。工作区只有清单、资料、成果三个主要入口，计价设置、工程概况和操作记录从「工程信息」进入。测算、材料匹配、审核与汇总统一归入成果，可直接切换；刷新不会切走当前页面。对话卡片只突出最新结果，其他结果按需展开。导入不确定的表格时提示核对，确认后继续导入。工程上下文、任务状态与主题同步。

数据库和文件存储通过 `.env` 设置：

```dotenv
DATABASE_URL="file:./dev.db"
STORAGE_DIR="./storage"
```

在 Harness 的「设置 → 模型」配置模型与密钥；也可以按官方方式设置 `DEEPSEEK_API_KEY`。原先的 `MODEL_*` 配置已不参与对话执行。

## 工作流程

1. 点击「新建工程」，填写名称后直接进入该工程的 Agent 对话。
2. 在对话区导入 Excel 或带文本层的 PDF；需要确认时点击「核对并确认导入」，修改表格后先保存，再确认导入。
3. 直接向助手描述报价、检查或汇总任务，也可点击空对话中的任务按钮。
4. 点击结果卡片查看明细，需要修改清单时在对话中批准写回；计价条件可从「工程信息 → 计价设置」填写。
5. 在成果页切换测算、审核或汇总结果，导出 Excel。

主材询价只写主材暂估价，综合单价由定额组价生成。缺主材价的测算默认不写回。管理费率、利润率未确认时可按零预览，写回前必须明确填写；未设置税率暂不计税并提示。已导入的措施和其他项目金额优先，包括明确为零的金额。

工程清单中，分部分项和单价措施编辑工程量或综合单价，总价措施和其他项目直接编辑金额；点击数值开始编辑，再点保存或取消。也可用 Enter 保存、Tab 保存并进入下一格、Esc 取消。未保存的修改会提示保留或放弃；保存会留下可撤销记录。总价反算保留总价措施和其他项目金额，只调整允许范围内的有量有价项。

清单 Excel 导出按源文件和工作表分别输出，保留费用类别与来源；同名或超长工作表名自动处理。保留源格式写回仅支持有效的 `.xlsx`，使用导入时确认的列映射；`.xls`、PDF 等资料仍可导出为新的清单 Excel。

## 结构

- `harness/cordis.patch.yml`：官方 Web 配置的造价适配。
- `harness/plugin/host.ts`：原生造价工具、确认与业务执行记录。
- `harness/plugin/client.tsx`：专业工作台入口及项目会话关联。
- `cost-engine/`：确定性的金额、工程量、定额组价和费用计算。
- `src/ui/`：项目总览、清单、映射、组价结果、计价设置与变更记录。
- `agent/runtime.ts`：确定性的文件导入；模型对话只由 Harness 执行。

默认使用「安装工程造价」Agent 预设，保留原生问答确认和长对话压缩；导航围绕工程组织，每个工程绑定独立会话。编程预设、通用文件写入与终端工具关闭。材料库、定额库继续通过专业后台管理。
